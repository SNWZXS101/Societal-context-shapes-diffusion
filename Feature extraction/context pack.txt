[PROJECT CONTEXT PACK — PINN + f(t) 框架]

模型与记号
- 省内第 w 波、属于省 i；变异株标签 k_{iw}∈{Original, Delta, Omicron}（仅作标签）。
- ODE: Ẋ = { dSe/dt=-f(t); dS/dt=f - βSI/N; dI/dt=βSI/N-γI; dR/dt=γI }，γ=1/7；β由R0×γ（2.5, 5, 8.2）给定。
- N=S+I+R；PINN 学得 f(t)。

关键特征（每波一行，均已算好或需代码计算）
- ϵ = c·MAD(f)，c∈[1.0,1.5]；近零带：|f|≤ϵ。
- t_inc-slope = argmax_t d/dt(βSI/N)；t_f,max = argmax f。
- 事件时刻：t0=inf{t≥t_f,max: f(t)<−ϵ}；T_ϵ=inf{|f(t)|≤ϵ}。
- Δ_early = t0 − t_inc-slope（未转负用 T_ϵ 仅作描述；评分另有惩罚）。
- 过零斜率 κ = 局部斜率(f, t0 或 T_ϵ)。
- 面积：A+ = ∫ f·1{f>ϵ} dt；A− = ∫ |f|·1{f<−ϵ} dt；A−^(ϵ)=∫ max(0, ϵ−f)·1{f≤ϵ} dt；
  ρ_ϵ = (A− + 0.3·A−^(ϵ)) / max(A+, ε)。
- 无量纲：  f̃1=(β/N)·f；f̃2= f / (βSI/N)； early-mean( f̃1 ) 在前 q=0.30 窗口（短波自适应）。
- tf2_peak = max_t f̃2，及其发生时刻 t_tf2_peak。
- 质量标记：flag_multipart（多峰/二次转正）；tail_short=1 若 T_tail<14 天；
  权重 ω = w_tail = min{1, (T_tail/14)^1}，T_tail = t_L - max(t_f,max, t_inc-slope)。

反事实（固定 β,γ 与初值）
- 左移 δ∈{3,5,7} 天；负相放大 η∈{0.1,0.2}；
- 目标导向：令 ṙ≡α=−r(t0)/T, T∈{7,10,14}，则 f*(t)= [N/(1−s)]·(α/β + β s i)；数值上 3 日平滑与低尾截断。
- 指标：C=∫βSI/N dt；%Avoided = 100·(C−C_cf)/C。

评分（全体 210 波为同一比较集）
- score(x)=100·(rank(x)−1)/(n−1)；方向统一：越好→分越高；对“越小越好”的量用 score(−x)。
- RRI = 0.40·score(−Δ_early) + 0.30·score(−κ) + 0.30·score(− early-mean f̃1 )
        − λ^(neg) − λ^(multi)，其中 λ^(neg)=5（未入负相），λ^(multi)=3（multipart）。
- MEI = 0.30·score(ρ_ϵ) + 0.10·score(−tf2_peak) + 0.10·score(−t_tf2_peak) + 0.50·score(%Avoided)
        − λ^(multi)。
- 省内聚合： RRĪ_i = Σ_w ω_iw RRI_iw / Σ_w ω_iw（MEI 同）。
- 价值增量（去结构差异）：对 S∈{RRI,MEI} 拟合
  S_iw = α + v_i + u_{k_{iw}} + X_iw^T β + ε_iw,  Var(ε)=σ^2/w_tail 。
  取 v_i 的后验均值映射到[0,100] → RRI_i^VA, MEI_i^VA；综合分 SRS_i=0.4·RRI_i^VA+0.6·MEI_i^VA。
- 进步度 LPI：首末波 ΔSRS 天花板校正 + 省内趋势斜率（Theil–Sen 可选）。

建模与诊断（供代码与结果复现）
- 特征层 HBM（每个连续特征单独）：正态似然，省/阶段随机截距；尺度用 half-Student-t(ν=3)；采样 NUTS，R̂<1.01, ESS 充足；PPC 合格。
- 生存（速度证据）：Cox + frailty v_i（HR>1=更快收紧=正向）；PH 用 Schoenfeld 检验；备选 AFT(log-normal/log-logistic)。
- 结局（负担证据）：log C, log I_max ~ 加权交叉分层正态（w_tail 降权）；PPC；WAIC/PSIS-LOO 选设定。
- UQ & 稳健性：分层 bootstrap(B=1000) × (c,h,q) × (δ/η/T) × 设定替代；输出分与排名的95%区间与Top-10概率。
